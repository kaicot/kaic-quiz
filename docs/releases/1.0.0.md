# 퀴즈 리포터 1.0.0

상태: 배포 준비 완료. 릴리즈 태그 `v1.0.0`.

구글 폼으로 본 5지선다 퀴즈를 채점하고, 학생마다 "왜 틀렸는지" 알려 주는 PDF 리포트를 만드는 첫 배포
버전입니다. Windows 10/11(64비트)용 포터블 프로그램이며 Python 설치가 필요 없습니다.
**자료 형식: 1**(`Data\FORMAT.json`).

## 받는 파일

- `Quiz-Reporter-v1.0.0-windows.zip` — 프로그램 폴더 전체
- `Quiz-Reporter-v1.0.0-windows.zip.sha256` — 내려받은 파일이 온전한지 확인하는 값

쓰기 가능한 전용 폴더(예: `D:\퀴즈리포터\`)에 풀고 `Quiz Reporter.exe`를 실행합니다.

## 할 수 있는 일

- **채점**: 구글 폼 응답 CSV(권장)나 연결된 스프레드시트 xlsx. 수업 뒤 복습으로 다시 푼 응답은 마감 시각을
  자동으로 제안해 빼고, 같은 학번은 첫 응답만 씁니다. 학번이 8자리 숫자가 아니면 '학번 확인 필요'로 표시합니다.
- **문항표와 AI**: 출제 프롬프트, 해설 만들기 프롬프트를 복사해 AI에게 맡기고, AI가 준 표를 붙여넣거나 엑셀로
  불러옵니다. 공개 폼 주소로 문항표 틀(문제·보기·정답)을 만들 수 있습니다. 문항표가 없어도 CSV 점수로 기본
  리포트를 만듭니다.
- **학생별 리포트**: 인쇄용 묶음 PDF(학생당 1쪽, 이름 가나다순)와 학생별 PDF. 점수와 반 평균, 단원별 정답률,
  틀린 문항마다 고른 답·정답·틀린 이유, 함정 유형, 복습 우선순위. 흑백 인쇄에도 읽기 좋게 만들었습니다.
- **채점결과 엑셀**: 학생별 고른 보기 번호(숫자), 문항 분석, 학생별·반 전체 함정, 제외된 응답, 문항표, 색 설명.
- **퀴즈 관리**: 홈의 최근 퀴즈 카드, 퀴즈 목록(리포트·폴더 열기, 문항표 바꿔 다시 만들기, 삭제), 휴지통.
- **기타**: 도움말(F1), 새 버전 안내(하루 한 번 버전 번호만 확인, 자동 설치 없음), 이전 버전 자료 가져오기.

## 개인정보

때는 버전 번호만 보냅니다.

## 검증 결과

- **실제 자료**: 실제 수업 퀴즈 2개(각 33건·10문항)로 48개 항목 일치. 복습 응답만 정확히 제외(1건, 2건),
  점수 = 구글 폼 문항별 점수 합(66건 모두), 공개 폼 틀의 보기·정답 일치, 묶음 PDF 쪽수·개별 PDF 수·채점결과
  엑셀 학생 수 = 채점 인원(32명, 31명), 다시 만들기·삭제·복원·이전 자료 가져오기 뒤에도 같은 결과.
  실제 자료는 임시 폴더에서만 쓰고 지웠습니다.
- **배포 폴더 점검(54항목)**: 필수 파일·버전 정보, 쓰지 않는 Qt 모듈·GPL 전용 모듈 없음, 학생 자료가 될 수
  있는 파일(csv·xlsx·pdf) 없음, ZIP과 확인값 일치.
- **실행 점검(24항목)**: Python이 없는 임시 폴더에서 EXE로 채점 → PDF(맑은 고딕 포함) → 채점결과 엑셀 →
  다시 만들기 → 삭제·복원, 첫 실행 파일 생성, 중복 실행 방지, AppData에 쓰지 않음.
- **OMR Grader 없이 단독 실행**: 새 Python 환경에 퀴즈 리포터만 설치해 같은 흐름 확인.
- **개인정보 누설 점검**: 실제 학번·이름·문제 글을 저장소의 모든 커밋, 작업 폴더, 배포 파일과 대조해 0건.
- **자동 테스트**: 220개 통과(1개는 이 PC 권한 문제로 건너뜀), 코드 검사(ruff·mypy) 통과.
